# 🛒 Full-Stack E-Commerce Platform

## Overview
A modern full-stack e-commerce application with a robust backend, a responsive React frontend, and integrated shopping cart and payment features.

## Features
- 👤 User registration & authentication
- 🛍️ Product listing & search
- 🛒 Shopping cart (Redux powered)
- 💳 Order checkout with payment gateway integration
- 🧾 Order history & confirmation

## Tech Stack
- **Frontend**: React, Redux, React Router
- **Backend**: Node.js, Express.js
- **Database**: MongoDB
- **APIs**: RESTful API design

## Getting Started

### Backend Setup
```bash
cd server
npm install
npm run dev
```

### Frontend Setup
```bash
cd client
npm install
npm start
```

### Environment Variables (server/.env)
```
MONGO_URI=mongodb://localhost:27017/ecommerce
```

## Folder Structure
```
ecommerce-platform/
├── client/     # React App
└── server/     # Express API Server
```
